# Support

## Where to ask what

- Use GitHub Issues for bugs, regressions, and concrete feature requests.
- Use the issue templates when they fit the problem.
- Use the maintainer profile for direct contact when an issue should not be public:
  - https://github.com/DiogoRibeiro7

## What to include

For technical questions or bug reports, include:

- crate version, branch, or commit SHA
- Rust version from `rustc --version`
- operating system
- minimal reproduction code when possible
- expected behavior and actual behavior

For numerical issues, also include:

- copula family
- parameter values
- input point(s)
- whether the issue is reproducible or intermittent

## Response expectations

This is an actively developed project, but support is provided on a best-effort basis. Clear, reproducible reports are much easier to act on than broad descriptions.
